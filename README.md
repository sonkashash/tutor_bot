# Бот для заявок на пробный урок

Воронка: /start → выбор класса → описание и цена → «Записаться на пробный» → тебе приходит уведомление с контактом ученика.

## Запуск

1. В Telegram открой @BotFather → `/newbot` → получи токен.
2. Скопируй `.env.example` в `.env` и вставь токен в `BOT_TOKEN`.
3. `npm install` → `npm run dev`
4. Напиши своему боту `/id`, скопируй число в `ADMIN_CHAT_ID`, перезапусти бота.
5. Заполни тексты и цены в блоке «НАСТРОЙКИ» в `bot.ts`.

## Деплой

Подойдёт любой хостинг, где крутится Node-процесс: Railway, Render, Fly.io или VPS (через `pm2 start "npm start"`).
Работает через long polling, поэтому домен и HTTPS не нужны.

## Как работает контакт

- Если у ученика есть @username — заявка уходит сразу, в уведомлении будет ссылка на профиль.
- Если нет — бот попросит поделиться номером телефона кнопкой.
